# Runtime Return Limited Local Smoke Fixtures

These fixtures are static safe IRIS adapter packets for the v1.1.7 limited
local runtime smoke candidate. They are not runtime readiness evidence, not
real TTS evidence, not ASR evidence, not Live2D renderer evidence, not benchmark
evidence, and not merge evidence.

The fixtures intentionally avoid raw audio, endpoint values, secrets, tokens,
model paths, datasets, benchmark fields, command fields, and canonical runtime
envelopes. The unsafe fixture is used only to prove fail-closed behavior.
